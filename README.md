# Bank Customer Churn Analysis Dashboard (Excel)

## Overview

This project analyzes customer churn behavior in a banking dataset using Microsoft Excel. The objective was to identify factors associated with customer attrition and present actionable insights through an interactive dashboard.

---

## Project Objectives

* Analyze customer churn patterns
* Identify demographic and behavioral factors associated with churn
* Build an interactive dashboard for business decision-making
* Demonstrate data cleaning, transformation, analysis, and visualization skills

---

## Dataset

The project uses customer demographic and account information, including:

* Customer ID
* Geography
* Gender
* Age
* Credit Score
* Balance
* Number of Products
* Active Member Status
* Estimated Salary
* Exited (Churn Indicator)

---

## Data Preparation

The following cleaning and transformation steps were performed:

* Removed mismatched customer records
* Standardized geography values
* Converted balance values to numeric format
* Merged customer and account datasets using XLOOKUP
* Created Age Groups
* Created Balance Groups
* Created Credit Score Categories

---

## Analysis Performed

### KPI Metrics

* Total Customers

### Customer Segmentation

* Churn by Geography
